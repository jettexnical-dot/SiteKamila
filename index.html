FAQ

Частые вопросы

Ответы на самые популярные вопросы о KAMILA. Не нашли свой — напишите в Telegram.

Да, базовый «Локальный» режим работает полностью офлайн. Распознавание речи идёт через модель Vosk, которая загружается на ваш ПК. Управление системой, таймеры, погода (после первого запроса с кэшем) — всё это доступно без интернета.

Интернет нужен только для режима «Нейросеть» (запросы к OpenRouter), генерации изображений и первой загрузки моделей.

Минимальные требования:

· Windows 10 / 11 (64-bit)
· 4 ГБ оперативной памяти
· 500 МБ свободного места на диске
· Микрофон (встроенный или USB)
· Python 3.10+ (для запуска из исходников)

Для режима «Нейросеть» желательно 8 ГБ RAM и стабильное интернет-соединение.

API-ключ хранится только локально в файле kamila_api_key.txt в папке с программой. Он никуда не отправляется, кроме как напрямую на сервер OpenRouter для выполнения ваших запросов.

KAMILA — open-source проект с открытым кодом. Вы можете самостоятельно проверить, что ключ не передаётся третьим лицам.

При активации PRO генерируется уникальный ID вашего компьютера на основе характеристик системы (имя ПК, процессор, серийный номер диска C:). Этот ID привязывается к ключу активации.

Это значит, что один ключ работает только на одном ПК. Перенести активацию на другой компьютер нельзя — нужно приобретать новый ключ.

Да, KAMILA поддерживает пользовательские TTS-модели. Вы можете заменить файл v5_ru.pt в папке models/ на свою обученную модель Silero или использовать другой TTS-движок.

Для распознавания речи можно заменить модель Vosk на любую совместимую. Все пути конфигурируются в коде.

Протокол — это макрос, последовательность команд, которые выполняются одна за другой. Например, протокол «Утро» может содержать: открой браузер, включи новости, покажи погоду.

Протоколы можно записывать голосом (KAMILA будет запоминать все ваши команды), сохранять в JSON-файлы и добавлять в автозапуск — тогда протокол выполнится сразу при запуске программы.

Введите токен бота (получить у @BotFather) в настройках KAMILA. Бот запустится автоматически и будет ждать команд в Telegram.

Через бота можно: делать скриншоты, записывать экран, управлять громкостью, запускать приложения, смотреть нагрузку системы, управлять файлами, убивать процессы и многое другое. Полный список команд — в меню бота.

KAMILA автоматически определяет лучший микрофон в системе. Если распознавание не работает:

1. Проверьте, что микрофон выбран устройством ввода по умолчанию в Windows
2. Дайте разрешение на использование микрофона в настройках конфиденциальности
3. Перезапустите KAMILA — при старте программа выведет в лог выбранное устройство
4. Используйте текстовый ввод — все команды работают и через поле ввода
