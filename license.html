Проприетарное программное обеспечение

KAMILA — это проприетарный голосовой ассистент для Windows. Использование программы регулируется настоящим Лицензионным соглашением.

01 Предоставление лицензии

Оператор предоставляет Пользователю неисключительную, непередаваемую, ограниченную лицензию на использование программного обеспечения KAMILA в личных некоммерческих целях.

  • Лицензия действует на одном устройстве (привязка к HWID).
  • Срок действия — бессрочно для PRO-версии после активации.
  • Free-режим доступен без активации с временными ограничениями.

02 Разрешённое использование

  • Установка и запуск на одном персональном компьютере.
  • Использование всех функций в соответствии с документацией.
  • Создание и хранение локальных протоколов, заметок и файлов.
  • Подключение собственных API-ключей для ИИ-провайдеров.

04 Сторонние компоненты

KAMILA использует следующие сторонние компоненты с открытым исходным кодом:

  • Vosk — Apache License 2.0 (распознавание речи)
  • Silero TTS — проприетарная лицензия Silero (синтез речи)
  • PyQt6 — GPL v3 / Commercial (GUI-фреймворк)
  • pyttsx3 — Mozilla Public License 2.0 (фолбэк TTS)
  • pyautogui — BSD 3-Clause (автоматизация)
  • psutil — BSD 3-Clause (системная информация)
Обратите внимание: Используя KAMILA, вы также соглашаетесь с условиями лицензий всех сторонних компонентов. Тексты лицензий доступны в репозиториях соответствующих проектов.

05 Интеллектуальная собственность

Все права на программу KAMILA, включая исходный код, дизайн, графику, звуки и документацию, принадлежат Оператору.

  • Логотип и название «KAMILA» являются торговой маркой.
  • Пользовательский контент (протоколы, заметки) принадлежит Пользователю.
  • Сгенерированный ИИ контент — в соответствии с условиями провайдера.

06 Обновления и изменения

Оператор вправе:

  • Выпускать обновления через GitHub Releases.
  • Изменять функциональность в новых версиях.
  • Обновлять настоящее Лицензионное соглашение.

Продолжение использования после обновления соглашения означает согласие с новыми условиями.

07 Прекращение лицензии

Лицензия прекращается:

  • По инициативе Пользователя (удаление программы).
  • При нарушении условий соглашения Оператором.
  • По решению суда.

После прекращения лицензии Пользователь обязан удалить все копии программы.

08 Применимое право

Настоящее соглашение регулируется законодательством Российской Федерации. Все споры разрешаются в суде по месту нахождения Оператора.
